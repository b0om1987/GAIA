# GAIA Systems

A Flask-based corporate landing page and dashboard with a simulated cognitive inference backend.

## How to run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Start the server:
   ```bash
   python main.py
   ```

3. Open `http://localhost:5000` in your browser.
